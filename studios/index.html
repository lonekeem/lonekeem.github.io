Official studio page

Lone Keem Studios — Lone Keem (Kemoy Lilly)

Lone Keem Studios is a creative studio founded by Lone Keem (Kemoy Lilly). Lone Keem is the main name you’ll see on the work. This page collects the games, apps, channels, movies and books so a search for either name can find them.

Games and apps

App

Kemy

A free, kid-safe app from Lone Keem Studios with no ads: raise virtual Kemy Pals, explore the 3D Pal Park, play games, and watch Lone Keem Studios Originals. Created by Lone Keem (Kemoy Lilly).

Game

After the Quiet

A story-driven 3D zombie game by Lone Keem Studios. Mature 18+ horror action set in Riverside, Maine.
